# 🧮 Calculadora em JS

Um projeto simples que fiz para treinar **JavaScript**, **HTML** e **CSS** na prática. 

A ideia principal foi aprender a capturar eventos da tela, manipular o DOM e aplicar uma lógica funcional para resolver operações matemáticas.

---

## ⚡ Funcionalidades

- **Contas básicas:** Soma, subtração, multiplicação e divisão.
- **Limpar visor (`C`):** Reseta tudo de uma vez.
- **Apagar último caractere (`#`):** Funciona como *backspace* para corrigir digitações.
- **Tratamento de erros:** Se tentar calcular algo inválido, mostra `'Erro'` na tela em vez de quebrar a aplicação.
- **Limpeza automática:** Se clicar em um novo número após um erro, a tela limpa sozinha.

---

## 🧠 O que pratiquei nesse código

- Seleção de elementos no DOM (`querySelector` e `querySelectorAll`).
- Loop em elementos com `.forEach()`.
- Escuta de eventos com `addEventListener` e leitura de dados com `dataset`.
- Recorte de textos usando `.slice(0, -1)`.
- Uso de `try / catch` para tratar exceções com a função `eval()`.

---

## 💻 Como rodar

Basta baixar o projeto e abrir o arquivo `index.html` em qualquer navegador.
